    How to type and dictate
    • Type romaji and kana appears. Add a space between words.
    • A capital first letter makes a word katakana: DOITSU becomes ドイツ. Use “-” for the long mark ー.
    • The particle は is typed ha, even though it is read “wa”.
    • To dictate, tap the microphone on the iPad keyboard while a Japanese keyboard is active. Dictation often returns kanji. These phrases accept the usual kanji spellings, so a miss means the recognizer heard something different. Say it again, a little slower.
    • This page cannot use the microphone itself, because the viewer blocks it. Use the keyboard’s dictation key instead.
    • Listen plays a recording, so it sounds the same on every device. “Listen slowly” is the same reading with a pause between the parts, not a stretched one.
    • If a phrase has no recording yet, the device’s own Japanese voice reads it. If that is silent, install a voice in iPad Settings → Accessibility → Spoken Content → Voices.
